# Sự kiện MKT · MMH

App theo dõi kế hoạch & tiến độ sự kiện Marketing FY68 (GitHub Pages: `index.html`).

- **Tổng quan** (quản lý): lịch sự kiện FY68, bản đồ tiến độ sự kiện × hạng mục, việc cần xử lý, khối lượng theo người, hoạt động gần đây.
- **Việc của tôi**: việc được giao xếp theo hạn — tải file ấn phẩm / dán link bài đăng ngay tại chỗ.
- **Sự kiện**: hồ sơ từng sự kiện — đội thực hiện, tiến độ task lớn / task phụ, ấn phẩm & tệp, kế hoạch (đọc từ file kế hoạch), nhật ký.
- Đăng nhập: email công ty + mã 6 số (dùng chung phiên với Report Hub / CRM).
- Backend: `ManiMedicalHanoi/mmh-backend` ▸ `backends/marketing/MKT_EventHub.gs`. Dữ liệu: Google Sheet "MMH · Event Hub FY68" trong thư mục Drive Event FY68.
- Xem thử với dữ liệu mẫu: `index.html?demo=1` (`&as=Đức Anh` để xem như thành viên).
- App Quiz cũ: `quiz.html`.
